Privacy policy: ICSpin uploads

Last updated September 24, 2026.

"ICSpin uploads" is a private tool used by the owner of the ICSpin YouTube channel to upload videos to that channel and manage them. It is not offered to the public, and nobody else signs in to it.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos, set their titles, descriptions, thumbnails and privacy status, and read back the channel's own videos to confirm an upload worked.

What it stores

An access token is stored on the channel owner's own computer so uploads can run without signing in each time. No Google user data is stored anywhere else.

What it shares

Nothing. No data obtained through Google APIs is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.

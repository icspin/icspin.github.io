Privacy policy: ICSpin tools

Last updated September 24, 2026.

This policy covers two private tools used only by the owner of the ICSpin YouTube channel, for that channel. Neither is offered to the public, and nobody else signs in to them.

ICSpin uploads

With the channel owner's permission, it uses the YouTube Data API to upload videos to the ICSpin channel, set their titles, descriptions, thumbnails and privacy status, and read back the channel's own videos to confirm an upload worked. Its access token is stored on the channel owner's own computer.

ICSpin stats page

With the channel owner's permission, it uses the YouTube Data API and the YouTube Analytics API, read-only, to show the ICSpin channel's own view, like and analytics figures on a password-protected page. Its access token is stored in the page's private server-side storage on Cloudflare, which only the channel owner controls.

What is shared

Nothing. No data obtained through Google APIs is sold, shared with third parties, or used for advertising. It is used only to show the channel owner his own channel's information and to upload his own videos.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
